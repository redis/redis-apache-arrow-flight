# Tableau read validation specification

Record the tested client/backend versions, JDBC installation and connection
steps, discovered catalog/schema/table/columns, and expected preview values.
Distinguish successful discovery and data-preview reads from untested
worksheets, filters, aggregates, dashboards, extracts, joins and authentication.
Preserve the historical server revision and manual-evidence limits.

Update compatibility documentation and the testing policy to reflect the
requester's read-only Tableau scope. No runtime, dependency, write-back or
commercial feature implementation is in scope.
