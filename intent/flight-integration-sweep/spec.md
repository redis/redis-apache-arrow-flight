# Specification

Inventory all 27 deck routes, distinguishing the 21 candidates and six prior
routes. Execute real tool operations through Flight SQL/JDBC with unique
fixtures. Persist logs, JUnit, resolved versions, output artifacts and per-tool
scope. Use explicit native/application evidence for RStudio, Tableau and
Metabase. Missing or skipped tool checks must not count as passes. Exact known
upstream defects may be strict expected failures with tested workarounds.

Provide dependency profiles, a Make target, reproducible application procedures
and a manually dispatched workflow. Current main's live testing requires a
qualified Redis Enterprise backend with verified TLS/authentication; historical
OSS evidence must retain its actual source/backend and must not certify that
gate. No public driver/commercial boundary or Go dependency change is in scope.
