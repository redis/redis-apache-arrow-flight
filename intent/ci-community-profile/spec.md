# Acceptance

Community has one complete dataset endpoint, buffered SQL and no paid stream
admission. Enterprise assertions remain conditional on optimization capability.
Cancellation and shutdown must still abort active transports and release cursors.
Readiness requires a real SQL round trip; UNKNOWN is not backend readiness.
Community metrics return HTTP 204 with no body. The SQL bridge rejects a genuinely
unsupported struct; one-dimensional lists are supported by the pinned driver.

No runtime feature, driver dependency or entitlement policy changes are required.
