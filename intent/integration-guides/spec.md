# Integration guide specification

All 27 inventoried routes must link from the README and integration index to a
guide. Existing extra integrations remain discoverable. Each guide supplies
installation steps, a read example and a database write/read-back workflow,
or explicitly documents unavailable application writes and an external ADBC path.
Examples use disposable fixtures, autocommit and scoped cleanup. Historical
OSS evidence must not become Enterprise or TLS/authentication qualification.
New examples must not be described as executed integration tests.
