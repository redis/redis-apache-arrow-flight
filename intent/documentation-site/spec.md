# Acceptance

Use the README as the home page and publish all documents/assets under docs/.
Preserve relative documentation links and anchors; send repository source links
to GitHub. Do not publish unrelated repository files. Include canonical URLs,
search, and a sitemap at the redis.github.io project URL.

Pull requests must build the site in strict mode. Documentation changes on main
must deploy through GitHub Pages with deployment permissions limited to the
deploy job. Google indexing and Search Console ownership remain external to
the documentation build; do not claim indexing from deployment alone.
